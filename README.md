# testdb

Simple Spring Boot application (Gradle).

## Build

On Windows (PowerShell/cmd):

```powershell
.\gradlew.bat build
.\gradlew.bat bootRun
```

On Unix/macOS:

```bash
./gradlew build
./gradlew bootRun
```

## Tests

```bash
./gradlew test
```

## Notes

- Java 17+ recommended.
- Project generated with Gradle wrapper included.
